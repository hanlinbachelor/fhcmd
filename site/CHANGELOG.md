# 变更记录（CHANGELOG）

版本号规则：`主.次.补`（SemVer）
- **主**：改了会让人"不会用"的东西（配置格式、快捷键、默认行为大改）
- **次**：新增功能（新主题、新交互）
- **补**：修 bug、调颜色、改文案

每次发版做三件事：① 改 `souti.py` 里的 `__version__` ② 这里加一节 ③ `git commit -m "vX.Y.Z: 一句话"`

---

## v1.1.1 — 2026-10-20

**修复**
- 设置窗被置顶浮窗**完全遮挡**、根本没法用：改为**独立的置顶模态窗**（无父窗口 + `WindowStaysOnTopHint`），
  显示时 `raise_()` + 激活窗口两次；位置自动放到浮窗左侧空地，放不下就改右边或居中
- 关闭设置窗后自动把浮窗重新抬到最前

---

## v1.1.0 — 2026-10-20

**新增：设置窗口（发给别人也能自己填）**
- 右上角新增 **⚙** 按钮（右键菜单里也有「设置」）：填 `接口地址 / 模型 / API Key`，带**「测试连接」**，
  保存即生效，不用重启、不用手改 JSON
- 首次运行若没检测到 Key，**自动弹出设置窗**；截图时缺 Key 也会弹
- Key 用密码框显示，只写进本机 `config.json`，不上传任何地方

**新增：版本下载站（site/）**
- 版本选择 + 下载 + 下载次数 + sha256 校验值，深色页面与程序同一套视觉
- `serve.py` 默认 **80 端口**（地址不用带端口），被占用自动退到 8000/8080
- 页面二维码 `/qr.png`（按访问地址动态生成），手机扫码直达
- 一键发布新版本：`python site/add_release.py --version vX.Y.Z`
- 修掉 Windows 上 `allow_reuse_address` 导致两个进程抢同一端口的隐患

## v1.0.0 — 2026-10-20

第一个可用版本（此前都是边做边改，无版本记录）。

**核心**
- 无浏览器依赖的置顶浮窗，`Ctrl+Alt+Q` 全局热键框选屏幕区域
- 框选后直接把图交给视觉模型（DeepSeek `deepseek-v4-flash-vision-exp`），流式返回
- 输出固定四段：题目 / 答案 / 解析 / 考点；看不清的字用 ▢ 标注，禁止编造题干
- 截图**不落盘**，只进剪贴板 + 发给模型；支持文字追问（带上下文）、复制、清空、停止

**交互**
- 两档最小化：贴边悬浮小球（58px，单击展开、拖动吸边、右键菜单）→ 托盘隐藏区
- 框选光标：大号青色准星 + 全屏十字线 + 实时坐标 + 选区像素尺寸；Esc/右键取消
- 窗口位置/尺寸/主题/小球位置自动记忆

**外观**
- 两套主题，标题栏 `◐` 随时切换（含托盘/小球菜单）：
  - **镭射**：青蓝霓虹 + 深空黑
  - **液态玻璃**：低饱和灰调 + 燕麦白字；自己抓背后画面做模糊（只画在圆角内，所以没有直角残留）+ 顶部镜面高光 + 内缘亮边 + 底部反光
- 字体统一 **思源黑体 Noto Sans SC**；正文 10.5pt / 行高 158%
- **答案高亮条**：答案单独提出来 15.5pt 加粗 + 主题色淡底描边；「复制」只复制答案段

**工程**
- `pythonw` 静默运行，异常写入 `error.log`
- 桌面快捷方式 + 自制青色准星图标
- 随包 skill：`screenshot-answer-overlay`（可发给别人用他自己的 API key 复刻）
