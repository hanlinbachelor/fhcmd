# 变更记录（CHANGELOG）

版本号规则：`主.次.补`（SemVer）
- **主**：改了会让人"不会用"的东西（配置格式、快捷键、默认行为大改）
- **次**：新增功能（新主题、新交互）
- **补**：修 bug、调颜色、改文案

每次发版做三件事：① 改 `souti.py` 里的 `__version__` ② 这里加一节 ③ `git commit -m "vX.Y.Z: 一句话"`

## v1.3.3 — 2026-10-23

**新主题**
- **奶油**：暖白牛奶玻璃 + 莫兰迪绿/雾蓝/藕粉/淡紫四色分区，边框与高光柔和
- **千里江山**：底图用《千里江山图》高清扫描（公有领域），叠绢色蒙版与宣纸纹理；
  石青/石绿/赭石/头青分色标注，随窗口等比铺满

**界面**
- **可拖边框缩放**（四边/四角，最小 360×430），默认 470×660，尺寸记忆
- 「收起」悬浮球与托盘两档最小化不变

**公式渲染**
- 含中文的公式（`\text{即 }`）**剥掉中文后整体按数学排版**，不再整条退化成伪源码

- 渲染失败会写 `math_fail.log`，每次答案原文留档 `last_answer.txt`，便于排查

## v1.3.2 — 2026-10-21

**修复：打包版的公式渲染根本没生效（v1.3.1 的真 bug）**
- 根因：打包时为瘦身加了 `--exclude-module PIL`，但 **matplotlib 依赖 PIL**（`matplotlib.colors` 直接 import），
  于是 exe 里一 `import matplotlib` 就 `ModuleNotFoundError`，渲染静默失败 → 答案里直接摊出 LaTeX 源码
- 修正：PIL 重新打进包；其余安全裁剪保留（Qt 多余模块、matplotlib 无关后端、测试包）
- 新增 `反谋财害命器.exe --selftest-math`：在**真实打包环境**里渲染 3 个公式并把结果写到 exe 旁边
  的 `selftest_math.txt`，以后每次发版都能用一条命令验证渲染是否可用（这次就是靠它定位的）

**新增：设置窗里显示版本**
- 设置窗底部显示「版本 vX.Y.Z · 当前模型 xxx」，不用再靠状态栏猜自己装的是哪一版

## v1.3.1 — 2026-10-21

**界面与公式的手感修整**
- **主窗口默认放大**：440×620 → **520×780**（老配置里的小窗口会自动放大一次，你自己拉大的不受影响）
- **设置窗重做配色**：深底色 + 高对比文字，输入框描边清晰、聚焦高亮，「保存」用主色按钮；
  提示文字提亮到 9.5pt，不再灰底灰字
- **「测试连接」不再影响保存**：改成后台线程，界面不卡，测多久都能随手点「保存」；
  失败提示也改成「可先保存后重试」，不再像是阻止你保存
- **公式渲染更抗造**：`\boxed{...}`、`\dfrac`、`\text{...}`、`\operatorname` 这些 mathtext 不认的命令
  会自动剥壳/降级，**含中文的公式改用中文字体渲染**（以前会变成方块）；
  最后还有一层“纯文本兜底”，绝不会再把 LaTeX 源码直接摊在答案里

## v1.3.0 — 2026-10-21

**数学公式真渲染**
- 答案/解析里的 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 会渲染成**真实排版的公式图片**
  （matplotlib mathtext，**不需要装 LaTeX**），按主题文字颜色出图，深浅主题都清楚
- 裸写的 `x^3`、`a_{n}` 自动转成上下标；`\frac1n` 这种省略花括号的写法自动补全
- 公式与文字**垂直居中对齐**，不会被行高裁切；渲染失败自动退回原文，不会白屏

**剪贴板开关**
- 右键菜单新增「截图后复制到剪贴板」，**默认关闭**；勾选后框完图会放进剪贴板方便粘到别处

## v1.2.2 — 2026-10-21

**彻底不碰剪贴板**
- 「发送」在输入框为空时**不再读取剪贴板**，只提示“先输入题目或按 Ctrl+Alt+Q 框选”
- 框选截图后**不再写入剪贴板**（图片只在内存里直接送模型，不做任何中转）
- 唯一保留的剪贴板操作是「复制」按钮 —— 那是你主动点它复制答案

## v1.2.1 — 2026-10-21

**修复（都是 exe 版暴露出来的真问题）**
- **配置丢失**：打包后 `__file__` 指向临时解包目录，`config.json` 会写进 temp、重启就没了。
  改为打包时用 `sys.executable` 的目录 —— 配置、日志都落在 **exe 旁边**（已用模拟 frozen 环境验证）
- **误发剪贴板图片**：输入框为空时点「发送」会**直接把剪贴板里的图**当题目发出去，
  剪贴板里残留的旧图（例如之前那张“四史”截图）会被当题解一遍。
  现在会先弹一个小窗显示**缩略图**问你“要发送这张图吗？”，默认按钮是「取消」

## v1.0.0 — 2026-10-20

第一个可用版本（此前都是边做边改，无版本记录）。

**核心**
- 无浏览器依赖的置顶浮窗，`Ctrl+Alt+Q` 全局热键框选屏幕区域
- 框选后直接把图交给视觉模型（DeepSeek `deepseek-v4-flash-vision-exp`），流式返回
- 输出固定四段：题目 / 答案 / 解析 / 考点；看不清的字用 ▢ 标注，禁止编造题干
- 截图**不落盘**，只进剪贴板 + 发给模型；支持文字追问（带上下文）、复制、清空、停止

**交互**
- 两档最小化：贴边悬浮小球（58px，单击展开、拖动吸边、右键菜单）→ 托盘隐藏区
- 框选光标：大号青色准星 + 全屏十字线 + 实时坐标 + 选区像素尺寸；Esc/右键取消
- 窗口位置/尺寸/主题/小球位置自动记忆

**外观**
- 两套主题，标题栏 `◐` 随时切换（含托盘/小球菜单）：
  - **镭射**：青蓝霓虹 + 深空黑
  - **液态玻璃**：低饱和灰调 + 燕麦白字；自己抓背后画面做模糊（只画在圆角内，所以没有直角残留）+ 顶部镜面高光 + 内缘亮边 + 底部反光
- 字体统一 **思源黑体 Noto Sans SC**；正文 10.5pt / 行高 158%
- **答案高亮条**：答案单独提出来 15.5pt 加粗 + 主题色淡底描边；「复制」只复制答案段

**工程**
- `pythonw` 静默运行，异常写入 `error.log`
- 桌面快捷方式 + 自制青色准星图标
- 随包 skill：`screenshot-answer-overlay`（可发给别人用他自己的 API key 复刻）
