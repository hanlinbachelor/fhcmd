如果 Windows 提示「应用程序控制策略已阻止此文件」
Windows 11 的智能应用控制只放行有信誉/签名的程序，未签名的 exe 可能被拦。三选一：
① 用包里的源码版：双击 启动反谋财害命器.bat（需先装 Python 3.11/3.12，会自动装依赖）
② 放行 exe：右键 → 属性 → 勾「解除锁定」→ 确定
③ 关闭智能应用控制：设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制
